#### Features:
 - [x] Can connect petra wallet on testnet
 - [x] Can whitelist your own wallet
 - [x] Can check if your wallet is already whitelisted
 - [x] Can restrict minting if youre not whitelisted
 - [x] Can mint a token if you are whitelisted
 - [x] Can remove your own adreess to the whitelisted list
 - [x] Can display minted tokens that you minted
 - [x] Can show all of the tokens that are mintred
 - [ ] a=Add to whitelist still allows you to transact even tho you are already whitelisted
 - [ ] Remove from whitelist still allows you to transact despite not being whitelisted
 - [ ] Protected whitelisting, only the deployer can add wadresses to whitelist
 - [ ] Limited mninting for whitelisted users
 - [ ] Display images or details from the metadata of the token
 - [ ] Put a value to a token/ cost of minting
